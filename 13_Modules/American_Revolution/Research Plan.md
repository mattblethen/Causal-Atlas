# American Revolution Research Plan

## Pass 1 - Source Spine
- Gather 2-4 reliable sources for each event in the starter chain.
- Create one source note per source.
- Prefer primary sources for acts, declarations, speeches, letters, and congressional records.

## Pass 2 - Event Chain
- Create event notes from [[Seven Years' War]] through [[Declaration of Independence]].
- Link each event backward and forward.
- Identify the visible pressure in each event.

## Pass 3 - Forces and Threads
- Expand [[Imperial Debt]], [[Parliamentary Sovereignty]], [[Colonial Autonomy]], [[Mercantilism]], and [[Atlantic Trade]].
- Connect each force to events where it becomes visible.
- Expand active thread notes only after events have sources.

## Pass 4 - Actors and Priorities
- Create actor notes for the British Empire, Parliament, colonial assemblies, the East India Company, Patriot organizers, Loyalists, and Continental Congress.
- Build priority logs for British imperial administration and colonial resistance.

## Pass 5 - Maps and Summary
- Create one causal map for the whole module.
- Create one pressure map for imperial debt, sovereignty, trade, and autonomy.
- Write [[Module Build Summary]] with sources used and remaining gaps.

## Guardrails
- Do not promote unsourced claims into researched notes.
- Keep disputed or interpretive claims in `Research Notes` until supported.
- Record open questions in [[Research Queue]].
