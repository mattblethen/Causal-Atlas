# Source Index

Use this page to track evidence before claims are promoted into event, force, actor, or thread notes.

## Source Notes
- Add extracted source notes in `10_Sources/Source_Notes/`.
- Store downloaded or copied primary-source files in `10_Sources/Primary_Sources/` when licensing and provenance allow.
- Store secondary-source reference files in `10_Sources/Secondary_Sources/` when useful.

## Source Quality Ladder
1. Primary source from an archive, library, government collection, museum, or university.
2. Scholarly book, peer-reviewed article, or university-published educational material.
3. Museum, library, historical association, or recognized encyclopedia article.
4. General web summary used only as a pointer to better sources.

## Minimum Standard
- Every non-obvious factual claim should point to a source note or source link.
- Every source note should name the publisher, date, URL or citation, reliability, and connected notes.
- If sources disagree, mark the target note `confidence: medium` or `confidence: low` and explain why.
