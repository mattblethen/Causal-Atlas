# Causal Atlas Starter Vault

This is a starter Obsidian vault for building a causal, zoomable history knowledge base.

Start with:

- `00_Home/Home.md`
- `Codex Instructions.md`

Then have Codex populate the first proof-of-concept module in:

- `13_Modules/American_Revolution/`

The vault is designed around the pattern:

**event → pressure → decision → priority → consequence → thread**
